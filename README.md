# Image Analyzer Project
*Justified selection of techniques for the intended analysis*

## Short description


The aim of the project is to make a justified selection of techniques for the intended analysis, rather than to use as many tools as possible.
Various input formats,
various dimensions and resolutions,
various characteristics: a few photos, a few graphics/drawings,
flowcharts/scientific diagrams/sketches.
